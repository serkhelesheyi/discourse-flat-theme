## قواعد کلی (در همهٔ فازها)

1. قبل از تغییر، `pnpm lint` و `pnpm lint:types` سبز هستند؛ بعد از تغییر هم سبز می‌مانند.
2. رنگ و فونت فقط از متغیرهای هسته و color scheme؛ هاردکد رنگ ممنوع.
3. برای RTL: ویژگی‌های منطقی (`inline-start/end`، `inset-inline-*`) و انتخابگر `.rtl`؛ دست‌کاری سراسری `direction` انجام نمی‌شود.
4. هر تغییر محدود به یک فاز؛ فازها را جلوتر از ترتیب اجرا نمی‌کنیم.
5. سفارشی‌سازی فقط با APIهای عمومی و plugin-outletها؛ اتکا به پیاده‌سازی داخلی هسته ممنوع.
6. در پایان هر جلسه، وضعیت این سند به‌روز می‌شود تا کار قابل انتقال بماند.

## پرسشهای باز (پاسخ در ادامهٔ جلسات ثبت شود)

1. **نام ماه رویدادها:** الان عدد ماه + `rail.month_suffix` نمایش داده می‌شود (مثلاً «۱۰ ماه»). تبدیل به نام ماه تقویم (با `Intl` یا i18n هسته) یک تصمیم طراحی جداست و هنوز گرفته نشده (سند ۰۴، بند ۹-۵).
2. **ادغام `mobile-platform.scss`:** بزرگ‌ترین تکرار باقی‌ماندهٔ CSS (۳۸۹ خط، ۱۱۷ `!important`) که روی موبایل دو بار بارگذاری می‌شود. انجامش نیازمند آزمون زندهٔ موبایل است (سند ۰۵، بخش ۹-۲).
3. **کاهش ۱۶۰۲ `!important` هم‌پوشان با هسته:** نیازمند ماتریس دیداری فاز ۶ و تأیید چشمی است (سند ۰۵، بخش ۹-۳).
4. **مسیر انتشار ۳٫۱٫۰:** نسخه و CHANGELOG به‌روز شده‌اند؛ اگر آزمون زنده ایراد اصلاحی نشان دهد، نسخهٔ بعدی `3.1.1` (رفع ایراد) یا `3.2.0` (تغییر رفتار) خواهد بود.
